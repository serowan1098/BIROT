Enrollment System

C# / Windows Forms

A role-based school enrollment desktop application, developed as an academic group project. Admin, Student, and Faculty each get their own dashboard and screens.

  • Welcome screen with sign-up and log-in, role selection, password visibility toggle
  • Student: personal profile and an enrollment application form with submit confirmation
  • Faculty: attendance and grade entry, both with full NEW / ADD / UPDATE / DELETE record grids
  • Admin: dashboard plus student (15 fields) and teacher (7 fields) record tables with full CRUD
  • Record tables are ListView controls that populate inputs on row select and manage button states
Honest limitation: data lives in memory only — records disappear when the app closes, and login credentials are hardcoded in the form code rather than checked against a database. Adding persistence is the next thing to build.
C# Windows Forms ListView CRUD
Repository and screenshots — not yet published

Digital Finance Buddy

HTML / CSS / JS

A browser-based budget and expense tracker. Set a total budget, add expenses, and the remaining balance updates instantly. No framework, no build step.

  • Set and display a total budget
  • Add, edit, and delete expense entries
  • Live calculation of total expenses and remaining balance
  • Dynamic expense list built with DOM manipulation and per-row action buttons
  • Input validation with show/hide error states
  • Responsive two-column layout that collapses on smaller screens
This is a front-end tracker, not a full financial system. There is no database and no back end.
HTML5 CSS3 JavaScript DOM Manipulation
Repository and live demo — not yet published

Number System Converter

Visual Basic .NET

A Windows Forms application that converts values between binary, decimal, octal, and hexadecimal. A main menu opens four dedicated converter forms.

  • Conversion across all four number systems using Convert with a base argument
  • Per-format input validation — binary restricted to 0/1, hex to 0-9 and A-F, decimal and octal via Integer.TryParse
  • Clear and close controls on every form
Note: this is a Visual Basic .NET project and is separate from the C++ calculator below. The two are different projects and are not merged.
Visual Basic .NET Windows Forms

LookIT

UI/UX · Figma

A mobile UI/UX concept for a home security app built on an existing camera and speaker setup.

Most security cameras are something you watch. LookIT proposes the opposite: a two-way voice interaction point, so you can actually talk to a visitor or delivery person when you're not home — with AI-assisted voice interaction handling the conversation when you can't answer.

  • Mobile interface design and prototyping
  • Home security user flows and visitor interaction
  • Voice interaction and user controls
  • AI-assisted voice interaction concept
This is a design prototype and concept, not a released application. Nothing here is implemented or deployed.

05 / Mindset

Perseverance + Continuous Learning

Software development, to me, is a cycle. Not a straight line.

Learn→Build→Get it wrong→Fix it→Try again

Perseverance means finishing a project even when the parts I haven't learned yet make it hard — then coming back to rewrite it properly. Continuous learning means the version I finished last week was never the best version I'll write.

That's why this portfolio is a work in progress rather than a finished product. It's honest about where I am, and it's moving.
